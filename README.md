# Portfólio Pessoal — HTML, CSS e JavaScript
https://portfolio-tpwt.vercel.app/
Este projeto é um portfólio pessoal desenvolvido com **HTML, CSS e JavaScript**, criado como parte dos meus estudos em desenvolvimento web.

O objetivo foi colocar em prática conceitos fundamentais de desenvolvimento Front-End, construindo uma página responsiva, organizada e com interações utilizando JavaScript puro.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Flexbox
* Media Queries
* Manipulação do DOM
* Eventos JavaScript
* Localização de elementos com `querySelector`
* Manipulação de classes com `classList`
* Validação de formulários

## ✨ Funcionalidades

* Página inicial com apresentação pessoal
* Seção "Sobre mim"
* Seção de habilidades
* Cards responsivos
* Menu de navegação
* Tema claro e escuro
* Mensagem de saudação de acordo com o horário
* Formulário de contato
* Validação dos campos do formulário
* Efeitos de hover e transições
* Layout responsivo para diferentes tamanhos de tela

## 📚 O que pratiquei

Durante o desenvolvimento deste projeto, pratiquei conceitos importantes como **HTML semântico, Flexbox, responsividade, manipulação do DOM, eventos, funções, condicionais, variáveis e validação de dados**.

Este projeto representa uma etapa dos meus estudos e faz parte da minha evolução como desenvolvedor Front-End.

## 🎯 Próximos passos

Pretendo continuar evoluindo este projeto e aplicar os conhecimentos adquiridos em projetos cada vez mais completos, avançando posteriormente para tecnologias como **React e desenvolvimento Full Stack**.
